# java-racingcar-precourse

# 기능 구현 목록

## 입력
- 경주할 자동차 입력 받아 저장하는 기능
- 총 이동 횟수를 입력 받아 저장하는 기능

## 자동차
- 이름으로 자동차를 생성하는 기능
- 입력 받은 자동차 이름들을 자동차 객체로 전환하는 기능

## 경주 진행
- 자동차의 전진 기능 (0에서 9 사이에서 무작위 값을 구해 4 이상인 경우 전진)
- 각 자동차의 전진을 한 차례 진행하는 기능
- 경기 결과를 저장하는 기능
- 한 차례의 결과를 출력하는 기능
    - 각 차의 이름과 해당 차례의 진행 결과를 - 표시로 출력
- 사용자가 정한 이동 횟수 만큼 차례를 진행하고 그에 따른 차수별 결과를 출력하는 기능

## 우승자
- 우승자를 합산해 정하는 기능
- 우승자를 출력하는 기능 (우승자가 여러 명일 경우 쉼표를 이용하여 구분해 출력)

## 검증
- 자동차 이름 검증 기능(5자이하)
- 잘못된 값을 입력할 경우 IllegalArgumentException을 발생시키는 기능
  - 이름이 중복되는 경우, 에러 처리하는 기능
  - 시도 횟수가 음수인 경우 처리 기능
